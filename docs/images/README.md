# Images

The screenshots of the README. They are taken from the demo dashboard (`npm run dev`, open `http://localhost:5173/?demo=1`, trace `POST /orders`), dark theme, 1600 x 1000, saved as JPEG (about 250 KB each). Retake them when the dashboard changes.

| File | Shows |
|---|---|
| `dashboard-flow.jpg` | The request with the metric strip, where the time went, the time map, the waterfall and the pinned step's Input / Output |
| `folders.jpg` | An open folder: its steps, the path above the list, the folder's own time axis |
| `filters.jpg` | A search that lists every match below the open folder with its path |
| `graph.jpg` | The Graph view: the path on the left, columns that grow to the right |
| `code.jpg` | Inside the code of `OrderService::create` with a line pop-up pinned |
| `database.jpg` | The Database tab with before / after cells |
| `problems.jpg` | The Problems tab |
| `replay.jpg` | The replay dialog (simulation or run for real) |
| `journal.jpg`, `group.jpg` | The journal, and the list grouped by route |
| `palette.jpg`, `record.jpg`, `light.jpg` | Ctrl+K, record from outside, the light theme |
